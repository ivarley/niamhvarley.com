# niamhvarley.com

Niamh's personal website. Some of it she writes herself, by hand, while learning
HTML — that is the point of those pages, not an accident of them. The rest are
things built *for* her: a ten-lesson iPad drawing course and a maze game made
for her tenth birthday. It is not a portfolio, a blog, or a product, and it has
no audience beyond her family. Everything is static files under `public/`, served
as-is.

## Three regimes

They look alike from the outside — all plain HTML — but they are edited in
completely different ways.

| Paths | What it is | How to change it |
|---|---|---|
| `public/draw/` | The Endless Drawing course | **Generated.** Edit the markdown, run `node build.js` |
| `public/10/` | *The Great Goose Chase*, a maze for her tenth birthday | Hand-edit `public/10/index.html` — one self-contained file, CSS and JS inline, images in `public/10/img/` |
| `public/index.html`, `public/hannah.html`, `public/more-hannah.html`, `public/images/` | Niamh's own pages about Hannah the cat | Hand-edit — but see below |

## Invariants

**Never hand-edit the HTML under `public/draw/`.** Every `.html` file in that
folder is generated by `public/draw/build.js` from `LESSONS.md` and
`GROWNUPS.md`, and the generated files are committed. Editing one appears to
work and is silently destroyed by the next build. Edit the markdown and run
`node build.js` in that folder. `public/draw/README.md` explains what the build
expects.

**Don't tidy up Niamh's pages.** `<font color="red">`, the unquoted `href`, the
ragged indentation, "austin TX" — she wrote those, and cleaning them up erases
her work and confuses her when she next opens the file. Change them only when
she has asked for the specific change.

**Links under `/draw/` are absolute, deliberately.** `build.js` sets
`const BASE = '/draw/'` and every generated `href` and `src` starts with it. The
host serves `niamhvarley.com/draw` without redirecting to `.../draw/`, and from
a URL with no trailing slash a browser resolves a relative `draw.css` against the
parent, 404s, and renders the page unstyled with dead links. Absolute paths are
correct either way. Don't switch them back to relative — commit `d44e6e7` exists
solely to undo someone doing exactly that.

## Running it locally

`./start` serves `public/` on port 8791. Opening the files directly as `file://`
URLs will not work for `/draw` — the absolute paths above need a document root.

## Design conventions

For the drawing course, `public/draw/CLAUDE.md` is the brief: who it's for, the
constraint everything else is downstream of, the voice, the device it's read on.
Read it before changing anything under `public/draw/`, and don't restate it here.

The other two regimes have no conventions to speak of. The cat pages are hers.
The maze was written to be one file that runs from anywhere.
